# Keylogger
This is the project i got, its basically a Keylogger
Developed a Keylogger application in Python to capture and record keyboard inputs in real-time.
.Utilized the pynput library to monitor and listen to keyboard events.
.Implemented an event-driven listener using keyboard.Listener.
.captured keystrokes and stored them securely in a text file (keyfile.txt).
.Applied file handling techniques to append logged keystrokes efficiently.
.Implemented exception handling to manage non-character key inputs.
.Demonstrated understanding of system-level input monitoring and background processes.
